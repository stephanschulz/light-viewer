# Spot Light Viewer

Single-file Three.js viewer for spot lights with a controllable beam angle (FWHM) and field angle.

- Beam / field angle, luminous flux, colour temperature
- Mounting height, tilt, rotation; open area, near-a-wall and room scenes
- Arrays (columns × rows with spacing)
- Ray-marched haze, auto exposure, floor beam/field outlines, polar plot and photometry readout
- Current parameters shown as a text block in the viewport

Open `index.html` in a browser (Three.js loads from jsDelivr).
